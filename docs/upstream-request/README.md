# Pictures for the request to upstream

The pictures that the feature request and the pull request to
[aitjcize/esp32-photoframe](https://github.com/aitjcize/esp32-photoframe) link to (raw URLs of this folder at a fixed commit), so
that they stay where the text says they are. All of them show made-up data: screenshots of the web UI with sample files and
simulated answers of the frame, and a simulation of the two random rotation rules. Nothing here is part of the firmware.
