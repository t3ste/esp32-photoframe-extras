Color Profile Editor

Edit the colors of the Calendar view. The picture is drawn by a copy of the frame's own renderer, so what you see here is what the frame draws, pixel for pixel.

    Profile
    This works when the page is opened from the frame itself. A profile sent to a slot is used once you select that slot under Settings → Agenda → Calendar color profile.
